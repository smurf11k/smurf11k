## `$ whoami`

Creative developer crafting expressive interfaces and the full-stack systems behind them.

I build web products end to end — from the first wireframe to the last migration.
My work sits where **engineering discipline** meets **creative experimentation**:
responsive interfaces, secure backend APIs, and the relational data layers that
hold them together. I care about clean architecture, accessible design, and
shipping things that actually work.

I'm also a **photographer and filmmaker**, with a strong visual side that shapes how I think about composition, motion, interaction, and atmosphere.

Outside of client work, I build **indie games**, contribute to **open source**,
and automate anything that gets in my way twice.
